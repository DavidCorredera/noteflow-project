# Configuración de IA

Para asegurar la consistencia del código, se ha configurado un archivo `.cursorrules` en la raíz del proyecto. Este archivo instruye a los asistentes de IA sobre el stack tecnológico estricto: Expo Router, FlashList, Zustand y TypeScript. 

El objetivo es evitar que la IA sugiera librerías obsoletas (como React Navigation antiguo) o componentes ineficientes (como FlatList para listas largas).
