# NoteFlow - Definición de la Idea

### 1. El problema
Hoy en día, las personas capturan información de diferentes maneras: a veces necesitan redactar un texto largo, otras veces necesitan una lista de tareas accionables, y en ocasiones solo quieren guardar una idea rápida visualmente categorizada. El problema es que muchas aplicaciones de notas obligan a usar un único formato genérico, o son herramientas tan complejas y pesadas que la fricción para apuntar algo rápido es demasiado alta. NoteFlow resuelve esta fricción ofreciendo tres espacios optimizados y separados para cada modelo mental (notas, tareas e ideas) en una app ultrarrápida y de acceso local.

### 2. El usuario objetivo
El usuario principal es un estudiante, profesional o creador de contenido que necesita un "segundo cerebro" de bolsillo. Es una persona con un ritmo de vida dinámico que usa su teléfono en el transporte público, entre reuniones o cuando le asalta la inspiración repentina. En su día a día, utilizaría la app para:
*   Redactar el borrador de un correo o apuntes de una reunión (Notas).
*   Llevar la lista de la compra o los pasos de un proyecto a corto plazo (Tareas).
*   Capturar chispazos de inspiración categorizados por color o temática para revisarlos después (Ideas).

### 3. MVP (Producto Mínimo Viable)
Para esta primera versión, las funcionalidades principales y obligatorias son:
*   **Gestión de Notas de texto:** Creación, lectura y eliminación de notas con título y contenido en texto plano.
*   **Gestión de Tareas (Checklists):** Creación de listas con múltiples ítems que se pueden marcar como completados/pendientes, y una barra de progreso visual.
*   **Gestión de Ideas rápidas:** Creación de notas cortas personalizables con colores de fondo y sistema de etiquetas (tags).
*   **Navegación principal:** Arquitectura de pestañas (Tabs) claras para separar los tres tipos de contenido.
*   **Interfaz de alta velocidad:** Listas de renderizado rápido (FlashList) para garantizar un scroll fluido incluso con muchos elementos.
*   **Persistencia local:** Guardado automático de todos los datos en el dispositivo del usuario sin necesidad de conexión a internet.

### 4. Backlog futuro (Funcionalidades opcionales)
Una vez estabilizado el MVP, se evaluará la implementación de:
*   **Búsqueda global:** Un input en la cabecera para filtrar en tiempo real en cualquiera de las pestañas.
*   **Sistema de archivado:** Capacidad de ocultar notas o listas terminadas sin tener que eliminarlas permanentemente de la base de datos.
*   **Sincronización en la nube:** Creación de cuentas de usuario para respaldar los datos en la nube y acceder a ellos desde múltiples dispositivos.
*   **Animaciones avanzadas:** Transiciones fluidas al crear, eliminar o filtrar elementos en las listas.
*   **Formato de texto enriquecido:** Soporte para Markdown o negritas/cursivas en las Notas estándar.
