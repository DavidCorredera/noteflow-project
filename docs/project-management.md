# Gestión del Proyecto

El desarrollo de NoteFlow se gestiona mediante un tablero Kanban para mantener el foco en las tareas activas y evitar bloqueos.

*   **Enlace al tablero:** https://trello.com/invite/b/69f8407e81dbc4c31e108d50/ATTI07d0b67d30cd99da066708b7fd688365180BFF11/noteflow-projects
*   **Flujo de trabajo:** Las tareas nacen en `Backlog` (ideas futuras) o `Todo` (MVP). Pasan a `In Progress` durante el desarrollo, a `Review` para pruebas/auditoría en el simulador, y finalmente a `Done`.
